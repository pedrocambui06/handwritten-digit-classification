# Handwritten Digit Classification with PyTorch

Projeto educacional de classificação de dígitos manuscritos usando uma
Convolutional Neural Network (CNN) implementada em PyTorch, treinada sobre
o dataset MNIST.

> Este projeto está em desenvolvimento. Esta seção será expandida com
> metodologia, arquitetura, resultados reais e análise de erros conforme
> o projeto evolui.

## Objetivo

Explorar o fluxo completo de um projeto de Deep Learning aplicado a visão
computacional: carregamento de dados, pré-processamento, construção de uma
CNN, treinamento, avaliação e análise de resultados.
